**Sonuç:** Kanal hook'u = **Güven (otorite/emek/ayna) + Kırılma + Sözleşme + Hızlı Kanıt.** Merak boşluğu çoğunlukla kısa menzilli; uzun menzilli döngü (ECO üçlü vaat, HRV bookend) en güçlü videolarda var → yeni sürümde **uzun menzilli döngü zorunlu**.

## 2. Hook'u izlemeye devam ettiren gerçek mekanizma (çapraz)
1. **Bekleme maliyeti sıfır:** İlk değer ≤ 40 sn'de. İzleyici "giriş bitsin" diye beklemiyor.
2. **Kimlik tehdidi/aynası:** "most people", "you" → izleyici kendini sahnede görüyor.
3. **Otorite transferi:** Harvard, FBI, Stanford, "700 sayfa", "2 hafta" → "bu boşa zaman değil".
4. **Paradoks vaadi:** "X yapmak Y'nin tersini doğurur" → açıklanmadan ayrılamazsın.
5. **Format kanıtı:** Hook = ilk ünite (POM, ECO) → "geri kalan da böyle dolu".

## 3. 9 HOOK ARKETİPİ (soyut formüller)

### H1 — PARADOKS VAADİ (yeni dönem varsayılanı; ECO)
```
[Emek/otorite kredisi: süre + hacim + kurum]
[Konunun görünüşü vs gerçeği: "seems X, but it's not"]
[Stakes: çoğu insan bunu bilmediği için Y oluyor]
"By the end of this video you'll understand why [ters sonuç 1], why [ters sonuç 2], why [ters sonuç 3]."
[İtirazı önceden söyle: "I know it sounds backwards"] + [kanıt sözü]
[Kes: "The year is ____." → ilk vaka]
```
Kural: 3 paradoksun **her biri** videoda adlandırılarak ödenmeli; en güçlüsünü ilk vakaya, birini ikinci yarıya sakla (ECO'nun hatası: hepsi %55'te bitti).

### H2 — AYNA SAHNESİ (DSP, EMY "This is you")
```
"Most people / This is you." + 2. şahıs gündelik sahne (3–6 somut detay)
[Zaman merdiveni: küçük davranış → tekrar → kimlik/kader]
[Teşhis: "So you keep creating the same ___ without realizing"]
[Aklama: "No wonder you can't ___" — suç mekanizmada]
[Merkezi soru: "So how do you ___?"]
```

### H3 — OTORİTE + VIA NEGATIVA + BİLMECE ZİNCİRİ (HRV)
```
[Kurum/unvan + kitap]
"X isn't about A. It's not about B. It's definitely not about C." + paradoks cümlesi
"So what IS X?" → 3 mikro senaryo, her biri "So what do you do?" + sürpriz çözüm
(en güçlü payoff 3.'de; çözümler ilkeye ad verilmeden)
"Here's a N-step framework…"
```

### H4 — İTİRAF + İNKÂR KIRILMASI + HIZLI DENEY (CIA)
```
[Anlatıcının duygusal itirafı: "The more I read about ___, the more ___ I get"]
[Tehlike: tetikleyici fark edilemiyor]
"They feel in control. They're not."
[≤30 sn'de ilk deney → tahmin oyunu]
```

### H5 — ETİKETLİ TEHDİT + KADEMELİ İSTATİSTİK + KİTLE FİLTRESİ (EMY)
```
"Here's a [sad/scary] truth about ___:" + [VERIFIED istatistik] + [istatistiğin istatistiği]
"How are you going to beat those odds?" (merkezi soru)
"I found the answer in ___ by ___."
"If you're [planning X] — or already [doing X] but feel [acı] — this video is for you."
```
Uyarı: İstatistik kaynaklı olmalı (kanalın %50/%75'i abartılı).

### H6 — TAMLIK SÖZLEŞMESİ (CAR — arama niyetli kitap-adı başlıkları)
```
[Kitabın statüsü + kanıtı (satış/yaş)] + [kime lazım: "if you want A, B, C"]
"[N] years old, still works because…" (modernleştirme itirafı)
"After this video you can say you've read it — every chapter."
```
Zayıf merak; mutlaka 1 açık döngü ekle ("…and one chapter completely changed how I talk to people — we'll get there.").

### H7 — TEZ + KONTRAST ÇİFT + Q-SNAP (POM)
```
[Kitabın tüm tezi tek cümle: "X has little to do with A and a lot to do with B"]
"Let me show you with two quick stories."
[Statü yüksek karakter → kötü davranış → "Want to know where he is now? [1 kelime]."]
[Statü düşük karakter → basit davranış → şaşırtıcı sonuç]
[Genelleme + aklama: "you don't need to be a genius"] + [3 küçük eylem] → "So, the first lesson is…"
```
Hook = gizli 1. ünite. Kontrast karakteri ~%40'ta başka bir ilke için geri çağır.

### H8 — YAZARIN EN SERT CÜMLESİ + TARTIŞMA SAVUNUSU (GRN)
```
[Kaynaktan en keskin fikir, anlatıcı sesiyle; atıf cümlenin sonunda]
"Some people think this author is [evil/dangerous]. I think it's because ___."
[Neden bu beceri hayati + kişisel tanıklık]
(30+ dk ise) "This is a long one — save it."
```

### H9 — KOŞULLU OTORİTE + KÜRATÖRLÜK + İKİLEM (KRU)
```
"If you could [talk to / study] [N elit kişi], you'd get this book."
"I picked the [M] best of [N]."
Ünite 1: "Imagine you could swap [senin varlığın] with [elit kişinin varlığı]. Would you?" → cevap neredeyse herkes için aynı → ilke.
```

## 4. 5-katman kombinasyon kuralları (yeni hook yazarken)
- **Zorunlu:** Narrative Commitment (ne öğreneceğini/formatı bil) + Disruption (bir varsayım kırılsın) + ≤40 sn ilk kanıt.
- **Zorunlu (kanalın zaafını kapatmak için):** En az **1 uzun menzilli Open Loop** — ikinci yarıda ödenecek (paradoks #3, bookend hikâye, "en tehlikeli olanı sona sakladım", kişisel matematik).
- **Stakes:** İzleyicinin *kendi* kaybı (para, yıl, ilişki) — kanalda zayıf; biz güçlendiriyoruz.
- Merak boşluğu: sonucu göster, nedeni sakla (Maryland: "gelir düştü" → neden?).

## 5. MODÜLER HOOK ÜRETİCİ (yeni konu → hook)
Girdi: konu, merkezi paradoks(lar), otorite, kontrast çifti (varsa), en iyi vaka, izleyicinin yanlış varsayımı.

Adımlar:
1. Konunun **arzu/korku kümesini** yaz (İnsanlar/Para/Zihin/Zaman/İş).
2. **Yanlış varsayımı** tek cümle yaz ("Saving money makes you rich").
3. Her arketip için 1 hook üret (en az H1, H2, H7 + konuya uygun 1–2 tane).
4. Her hook için doldur:
   | Alan | |
   |---|---|
   | Arketip | |
   | İlk cümle (≤15 kelime) ve işlevi | |
   | Kırılan varsayım | |
   | Merak boşluğu (saklanan bilgi) | |
   | Stakes (izleyicinin kaybı) | |
   | Uzun menzilli döngü + ödeme zamanı | |
   | İlk kanıt saniyesi | |
   | **Vaat doğrulama:** Video bu vaadi gerçekten ödeyebilir mi? Hangi ünite/Fact ID ile? | |
5. En yüksek skorluyu seç; kalanları alternatif olarak sakla (A/B test, Shorts).

### Hook vaat doğrulama testi (ret kriterleri)
- Vaat edilen sayı/ süre/sonuç scriptte açıkça ödenmiyor → RET.
- Hook'taki rakam VERIFIED değil → RET ya da ihtiyatlı dil.
- İlk somut içerik > 40 sn → kısalt.
- "Welcome", "In today's video", kanal adı, abone isteği → sil.
- İlk cümle izleyici yerine anlatıcıyı merkeze alıyor ve itiraf değil → yeniden yaz.

## 6. Örnek (özgün, kaynak videolardan kopya değil) — konu: Borç (Debt)
**H1:** "I spent a month reading what five economists and a bankruptcy lawyer wrote about debt. Most people think debt is the problem. It isn't — and that belief is exactly why they stay broke. By the end of this video you'll understand why the richest families borrow more than you do, why paying off your cheapest loan first can make you poorer, and why a 0% offer is rarely free. It sounds backwards. Let me show you."
- Vaat doğrulama: 3 paradoks → Ünite 2 (good vs bad debt), Ünite 4 (avalanche vs snowball, *reasonable vs rational* nüansıyla), Ünite 6 (deferred interest — ikinci yarıda!). Rakamlar dossier'den.
